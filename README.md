# DCReplace
Replaces a player with a random spectator if they get disconnected.

## Features
- Compatibility with EXILED Custom Roles.
- Prioritize replacement with players currently spectating the disconnected player.
- Gameplay Config `disconnect_drop: false` is required for this to work, but the plugin will automatically set it to false if it's true.

## Built for EXILED 9.8.1 and above.
